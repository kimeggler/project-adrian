# Asset Credits

Every asset used in Little Knight is listed here with its source and license.
No third-party or copyrighted game assets (Minecraft, Nintendo, etc.) may be used.

## Art

| Asset | Source | License |
|---|---|---|
| Knight sprites (idle, run, jump, fall, hurt, attack) and sword slash | Hand-drawn pixel data in `src/game/art/sprites.ts` | Original work, part of this project |
| Coins, spikes, flag, checkpoints, hearts, dust | Hand-drawn pixel data in `src/game/art/sprites.ts` | Original work, part of this project |
| Touch button icons (left, right, jump, sword, pause) | Hand-drawn pixel data in `src/game/art/sprites.ts` | Original work, part of this project |
| Slime enemy (walk, squashed) | Hand-drawn pixel data in `src/game/art/sprites.ts` | Original work, part of this project |
| Tiles (grass, dirt, stone block, castle wall) | Drawn with code in `src/game/art/tiles.ts` | Original work, part of this project |
| Parallax background (sky, clouds, mountains, hills) | Drawn with code in `src/game/art/backgrounds.ts` | Original work, part of this project |

The colors are picked from the widely used DawnBringer 32 palette (a list of
colors, not artwork).
